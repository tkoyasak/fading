# tree-sitter-fading

This is a fork of the Markdown parser for tree-sitter ([`tree-sitter-grammars/tree-sitter-markdown`](https://github.com/tree-sitter-grammars/tree-sitter-markdown)) taken at v0.5.1 (commit [2dfd57f](https://github.com/tree-sitter-grammars/tree-sitter-markdown/commit/2dfd57f547f06ca5631a80f601e129d73fc8e9f0)). The parser has been forked here for use in the Helix editor to enable custom syntax highlighting queries.
